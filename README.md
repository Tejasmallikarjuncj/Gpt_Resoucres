# GPT Resources

A collection of reusable GPT skills for learning and engineering work.
The project currently includes Antifragile learning skills that help turn
practical problems into deeper understanding and transferable knowledge.

## Project contents

- [Antifragile AI](gpt-skills/learn/antifragile-ai/SKILL.md): learning through AI, machine learning, mathematics, and software design problems.
- [Antifragile Embedded](gpt-skills/learn/antifragile-embedded/SKILL.md): learning through firmware, electronics, and embedded engineering problems.

## Structure

```text
README.md
gpt-skills/
└── learn/
    ├── antifragile-ai/
    │   └── SKILL.md
    └── antifragile-embedded/
        └── SKILL.md
```

## Getting started

Browse the skills above and open the relevant `SKILL.md` for its purpose,
usage conditions, and workflow. Each skill lives in its own folder so its
instructions can be reused independently.
