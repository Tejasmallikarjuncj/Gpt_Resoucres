# GPT Skills

Reusable skills organized by learning domain.

## Learning hierarchy

```text
learn/
├── AI/
│   └── antifragile-ai/
└── Embedded/
    ├── antifragile-embedded/
    └── anki-study-creator/
```

- **AI** — AI, mathematics, and software-system learning skills.
- **Embedded** — firmware, electronics, hardware–software, and embedded-learning skills.
- **anki-study-creator** — creates validated Anki study decks from learning conversations, including packaged media when available.

Each skill is self-contained in its own directory and includes a `SKILL.md` entry point.
